# 検出性能

正常音との近傍距離を使い、録音全体を正常・異常の2種類に判定します。

| 対象 | 正常 / 異常 | 正解 | 見逃し | 誤警報 |
| --- | ---: | ---: | ---: | ---: |
| 同梱サンプル50件 | 25 / 25 | 50 / 50 | 0 | 0 |
| 開発・校正用100件 | 50 / 50 | 99 / 100 | 1 | 0 |
| 追加確認73件 | 51 / 22 | 70 / 73 | 1 | 2 |

50件は100件に含まれます。100件は方式・しきい値の調整にも使用し、追加73件も開発データです。いずれも独立した未知音声の精度ではありません。

全173件のROC-AUCは0.998487、異常再現率は97.22%、正常音の誤警報率は1.98%です。
校正用100件の見逃しは `abnormal/00000105.wav`。正解ラベルやファイル名は推論に使いません。

赤い区間は、録音全体が異常判定で、かつ持続スコアが区間基準を超えた範囲です。区間の正解時刻による精度評価は実施していません。
